# windows-styling-guide

Agent-Skill: **Windows 11 Fluent Design → KDE Plasma** (Mica/Acrylic, Ecken, Elevation, Accent, Typografie).

Am besten zusammen mit `kde-theming` nutzen.

## Install (nur dieser Skill)

```bash
mkdir -p ~/.claude/skills && curl -fsSL https://github.com/TuxLux40/skills/archive/refs/heads/master.tar.gz | tar -xz --strip-components=2 -C ~/.claude/skills skills-master/skills/windows-styling-guide
```
