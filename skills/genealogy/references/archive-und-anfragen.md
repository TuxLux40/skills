# Archive: Kernliste, Anfragen, Nachverfolgung

Core list of repositories for the default regions plus the request workflow.
**Addresses, e-mail, opening hours and fees are not stored here** — look them
up on the repository's own website at the time of the request and state the
access date. Entries marked *(verify)* were not cross-checked.

## 2. Before writing

1. **Zuständigkeit:** which office created the record, and who holds it today
   (place at the date of the event → `regionale-besonderheiten.md`).
2. **Zugang:** is the record inside an access period? Who may apply, what
   proof of descent is needed (chain of certificates back to the user)?
3. **Online first:** is it already digitised? Then no request.
4. **Was genau:** one request, one clearly bounded question — event, person,
   date or span, place.
5. **Kosten:** look up the fee schedule; set a ceiling in the letter.

## 3. The letter

- In the repository's language: German, English, Dutch — write it directly.
  Hungarian and other languages you command less reliably: draft it, mark it
  as needing a check by a competent speaker, and add an English version
  below; many archives answer English.
- Content, in this order: what is requested (copy of the complete entry incl.
  marginal notes) → identifying data → what is documented vs. assumed →
  relationship and proof → Signatur if known → fee ceiling → contact.
- Never claim certainty you do not have; archives search better when told
  which details are estimates.
- It is a **draft**. The user sends it. Never state that something was sent.
- Templates DE/EN in `assets/vorlagen.md`.

## 4. Nachverfolgung / Tracking

Keep one list in the user's storage (`anfragen.md` or a table), one row per
request:

| Datum | Stelle | Betreff / Person | Weg (Mail, Formular, Post) | Aktenzeichen | Gebühr | Status | Antwort am | Ergebnis | Nächster Schritt |

Status values: `entwurf`, `gesendet`, `eingangsbestätigung`, `rückfrage`,
`beantwortet`, `negativ`, `keine antwort`.

- Before drafting a new request, check the list for an earlier one to the
  same repository on the same person.
- No reply after the period the repository states (often 4–12 weeks): draft
  a short, polite reminder quoting date and reference.
- A reply — positive or negative — becomes a source: file it, cite it
  ("Auskunft des Stadtarchivs … vom …, Az. …"), and log a negative reply with
  the scope the archive says it searched.
