# native-game-modding

Gameplay mods for native PC games via hooks / proxy DLLs (also under Proton): mechanism-first design, design
gate, project knowledge files, circuit breaker, and how modern games do aim, camera and movement.

## Install

```bash
mkdir -p ~/.claude/skills && curl -fsSL https://github.com/TuxLux40/skills/archive/refs/heads/master.tar.gz | tar -xz --strip-components=2 -C ~/.claude/skills skills-master/skills/native-game-modding
```
